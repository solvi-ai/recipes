# 06 · System 1 and System 2 on the world map of Pokémon Red

**Placeholder.** A video of the run will be added here.

What it will show: solvi walks the world map of Pokémon Red — 190 places and 447 exits, recorded from a real
playthrough as place names and exits (no ROM bytes, no game graphics) — through the game's first fifteen goals, twice.
System 1 is two rules over remembered routes; System 2 searches the world map the player builds as it goes; after each
goal, what System 2 found becomes System 1's routes. With solvi 1.0.0, the second run needed 2 slow decisions instead
of 147 and the fewest moves possible (62 instead of 183), and all 245 stored decisions replay without the game.

Until the video is here, the run can be replayed from a clone of the solvi repository (the recording lives in its
`spaces/pokemon/`):

```bash
git clone https://github.com/solvi-ai/solvi && cd solvi
uv run python examples/23_pokemon_world_map.py          # replays the bundled recording; no game needed
```

This folder will hold the video and a short description of what it shows. It will contain no ROM, no game
graphics and no game assets.
